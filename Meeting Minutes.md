**Part 1 — Project Demo** The students (Speakers 2 & 3\) demonstrated the robot live, covering JUNOAssist's core capabilities for task management, scheduling, health tracking and stress management:

* Voice commands to the robot ("Play music", "What are my schedules?", "Power off John") — wake-word activation initiates contact and opens the dashboard upon user confirmation  
* Dashboard showing disk view  
* Timer management — set and manage timers based on user specifications  
* Music playback — robot selected "Gentle Reset Mix" based on mood, with playlists categorized by mood/activity (e.g. "cool down," "gentle reset," "energy," "deep poker," "sadness," "happy")

* Graceful shutdown of the robot — powers down, closing connections and terminating the terminal session on request
